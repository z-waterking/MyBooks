## 授权与限制

Project Gutenberg 页面将这些版本标注为美国公版。不同司法辖区的版权期限可能不同。外国文学的现代中文译本通常具有独立版权，因此未从非授权来源下载；其余书单作品应通过购买或图书馆借阅获取。
