## 校验

- 8 个 EPUB 均包含 `mimetype` 与 `META-INF/container.xml`，结构有效。
- PDF 签名有效、未加密，共 227 页。
- TXT 文件非空；本次新增文件与下载目录源文件的 SHA-256 完全一致。
