# MyBooks

个人电子书与学习资料收藏库，按主题分类整理，附阅读进度追踪。

## 📖 数字书房主页

**主页地址：[https://z-waterking.github.io/MyBooks/](https://z-waterking.github.io/MyBooks/)**

主页支持浏览全部馆藏、按书名/作者/主题检索、分类与阅读状态筛选、查看图书简介，以及浏览综合、类型和文学奖项专题书单。阅读状态保存在当前浏览器中。

专项书单：[书单总索引](书单/README.md)｜[世界文学100本阅读路线](书单/综合/世界文学100本阅读路线.md)

> 注：`📚 已入库` 表示资料已整理进书库，无论文件是否同步到远端。

## 阅读状态图例

- `- [ ]` 未读
- `- [ ] 🟡 在看` 正在阅读
- `- [x] ✅ 已看完` 已完成

> 在 GitHub 网页上可直接点击复选框切换勾选状态，会自动提交。本地编辑时手动改 `[ ]` ↔ `[x]`，并加/去 🟡 / ✅ 标签。
