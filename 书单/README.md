# 专题阅读书单

这里集中管理按类型、奖项和文学传统整理的阅读路线。各书单不是简单的排行榜，而是尽量按照“入门 → 核心 → 进阶”的顺序安排。

## 状态标记

- 📚 已入库：电子书已经整理进书库，无论文件是否同步到远端。
- 行首 [ ]：尚未读完；读完后改为 [x]，并可添加 ✅ 已读。
- 🟡 在读：当前正在阅读。
- 没有入库标记不代表没有纸质书，只表示书库暂未收录电子版。

## 类型书单

- [科幻文学50本阅读路线](类型/科幻文学50本阅读路线.md)：从凡尔纳、威尔斯到赛博朋克与当代科幻。
- [推理与悬疑50本阅读路线](类型/推理与悬疑50本阅读路线.md)：本格、硬汉、社会派、心理悬疑与现代犯罪小说。
- [日本文学50本阅读路线](类型/日本文学50本阅读路线.md)：古典入口、近代文学、战后文学与当代文学。
