# 世界文学100本阅读路线

这是一条从好读、经典小说、现代主义到高难度文学的递进路线。目标不是机械完成排行榜，而是在读完后形成一张世界文学地图，理解不同时代、国家和地区的主要文学传统。

## 状态标记

- **馆藏标记**：“📚 已入库”表示电子书已经提交到仓库；“💾 本地馆藏”表示文件只保存在本地。
- **阅读标记**：每项行首的 [ ] 表示未读；读完后改为 [x]，并可在书名后添加“✅ 已读”。
- **在读标记**：正在阅读时保持 [ ]，并可在书名后添加“🟡 在读”。
- 当前仓库没有记录这份书单中哪些作品已经读过，因此“已读”状态暂不代为勾选。

示例：

- [ ] 《示例作品》— 作者　📚 已入库
- [x] 《示例作品》— 作者　📚 已入库　✅ 已读

## 使用说明

- 第 97—100 本是进阶重读或二次挑战，重复安排是路线设计的一部分。
- 不必强求连续啃完同一地区；遇到难书可以暂时跳过，读完同 Level 的其他作品后再返回。

## 推荐文学主线

如果不准备立即完成全部 100 本，可以先走这条 11 本主线：

《老人与海》→《局外人》→《傲慢与偏见》→《罪与罚》→《安娜·卡列尼娜》→《变形记》→《百年孤独》→《1984》→《长日将尽》→《素食者》→《红楼梦》

其中《局外人》篇幅短、文学性和思想性兼具，适合作为起点。
