## 9. 考试预约

- 中国大陆考生：通过教育部考试中心 IELTS 报名网站 <https://ielts.neea.cn> 报名
- 费用：约 2170 元人民币（2026 年标准）
- 考试日期：每月 3–4 个考试日，建议提前 1 个月预约（热门考点考位紧张）
