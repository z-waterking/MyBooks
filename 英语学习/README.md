## 快速开始

1. 进入 `IELTS网页/` 目录。
2. 双击 `index.html`，在默认浏览器打开。
3. 从主页顶部导航或卡片索引进入各模块。
4. 建议先看 **学习路线** → 再看 **阅读方法** → 然后按词汇 / 听 / 写 / 说节奏推进。

---

## 学习建议（一句话版）

- **不要直接从剑桥真题开始。** 先评估起点，按四个阶段循序而上。
- **方法先于刷题。** 每个题型都有固定流程，先学方法、再练真题。
- **错题归因比刷题更重要。** 用 `教程资源/IELTS_Reading_错题归因表.md` 复盘。
- **每周一次回顾**，不学新内容，只整理本周积累。
