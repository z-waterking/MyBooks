基本課文 CORE · 出门前的叮嘱

吉田明日の会議に遅刻しないでください。请不要迟到明天的会议。
李はい、気をつけます。好的，会注意的。
吉田書類を忘れないでください。请不要忘记文件。
李事前に確認しなければなりません。必须提前确认。
吉田レポートは金曜日までに提出しなければなりません。报告必须在周五之前提交。
李わかりました。締め切りを守ります。明白了，会遵守截止日期。
吉田何か 質問が ありますか。有什么问题？
李印刷は しなくても いいですか。不打印也可以吗？
吉田はい、データを 送れば いいです。对，发数据就行。
李分かりました。明白了。

応用課文 EXTENDED · 公司规定

小野この建物の中でタバコを吸わないでください。请不要在这栋楼里吸烟。
スミスすみません、知りませんでした。对不起，不知道。
小野廊下を走らないでください。規則ですから。请不要在走廊跑，规定。
スミスここではどんな規則がありますか。这里有什么规定？
小野静かにしなければなりませんが、難しくなくてもいいです。必须保持安静，但不必太严格。
スミス入口で 名前を 書かなければ なりませんか。入口必须签名吗？
小野はい、毎回 書いて ください。是，每次都写。
スミス靴を 脱がなくても いいですか。不脱鞋也可以吗？
小野ええ、土足で 大丈夫です。嗯，穿鞋没关系。
スミスわかりました。明白了。

文法

G1.動詞のない形ない形构成

V1（五段）：词尾う段→あ段＋ない／V2（一段）：去る＋ない／V3：する→しない、来る→こない。

①書く → 書かないV1
②食べる → 食べないV2
③する → しない／くる → こないV3
注意「う」结尾：「買う」→「買わない」（不是「買あない」）。ある → ない（不是「あらない」）。

G2.〜ないで ください请勿

ない形 + でください = "请不要…"，礼貌请求对方不做。

①廊下を 走らないで ください。请不要在走廊跑。
②ここで 写真を 撮らないで ください。请不要在这里拍照。
③心配しないで ください。请不要担心。
比「〜てはいけません」（禁止）语气温和。

G3.〜なければ なりません必须

ない形把「ない」换成 なければ なりません = "必须…"，含义务。

①毎日 薬を 飲まなければ なりません。必须每天吃药。
②パスポートを 持たなければ なりません。必须带护照。
③宿題を 出さなければ なりません。必须交作业。
口语缩略：「〜なきゃ」「〜なくちゃ」。

G4.〜なくても いいです不必

ない形把「ない」换成 なくても いいです = "不必/不做也可以"，解除义务。

①今日は 来なくても いいです。今天不来也可以。
②全部 食べなくても いいです。不用全部吃完。
③スーツを 着なくても いいですよ。不用穿西装哦。
对比：「〜なければなりません」必须 ↔ 「〜なくてもいいです」不必。

練習

1. 变 ない形

  1. 飲む →
  2. 食べる →
  3. 来る →
  4. する →
  5. 買う →
  6. ある →
▸ 答案
① 飲まない ② 食べない ③ こない ④ しない ⑤ 買わない ⑥ ない

2. 翻译

  1. 请不要迟到。
  2. 必须提交报告。
  3. 不用去银行也可以。
  4. 请不要在这里吸烟。
▸ 答案
① 遅刻しないで ください。
② レポートを 提出しなければ なりません。
③ 銀行へ 行かなくても いいです。
④ ここで タバコを 吸わないで ください。
