基本課文 CORE · 聊旅行经历

小野森さんは富士山に登ったことがありますか。森登过富士山吗？
森ええ、一度登ったことがあります。嗯，登过一次。
小野外国へ行ったことは？去过外国吗？
森フランスとドイツへ行ったことがあります。去过法国和德国。
小野ワンさんは？王呢？
ワン私はまだ日本しか行ったことがありません。我还只去过日本。
小野納豆を 食べた ことが ありますか。吃过纳豆吗？
ワンいいえ、まだ ありません。没，还没。
小野今度 一緒に 試して みましょう。下次一起试试吧。
ワンぜひ。好的。

応用課文 EXTENDED · 周末安排

李吉田さん、週末は何をしますか。吉田，周末做什么？
吉田ジョギングをしたり、料理を作ったりします。跑跑步、做做饭之类。
李温泉へ行ったことはありますか。去过温泉吗？
吉田はい、よく行きます。李さんも一緒にどうですか。去过，常去。李一起？
李いいですね。いつ 行きますか。好啊，什么时候去？
吉田来週の 土曜日は どうですか。下周六怎么样？
李大丈夫です。可以。
吉田温泉の 後で、おいしい 料理を 食べましょう。泡温泉之后吃顿好的吧。
李楽しみです。很期待。
吉田じゃ、決まりですね。那就这么定了。

文法

G1.動詞た形た形

た形与て形变化完全相同，只把「て→た、で→だ」。是简体过去时，也是后续语法的基础。

①昨日、公園を 散歩した。昨天在公园散步了。
②朝ごはんを 食べた。吃过早饭了。
③友達が 来た。朋友来了。
复习 て形变化（L15）：V1 く→いて、ぐ→いで、む/ぶ/ぬ→んで、つ/る/う→って、す→して。例外：行く → 行った（不是「行いた」）。

G2.〜た ことが あります经历

Vた + ことが あります = "有过…的经历"。否定「〜た ことが ありません」。

①スカイダイビングを した ことが あります。有过跳伞经历。
②納豆を 食べた ことが ありますか。吃过纳豆吗？
③富士山に 登った ことが ありません。没登过富士山。
询问次数：「何回 行った ことが ありますか」→「三回 行った ことが あります」。

G3.〜たり、〜たり します列举

Vた + り重复使用，最后加 します，表"做这做那"（不穷举）。

①音楽を 聴いたり、本を 読んだり します。听听音乐、看看书。
②週末は 掃除を したり、洗濯を したり します。周末打扫、洗衣。
③運動を したり、料理を 作ったり します。运动、做饭。
至少列举两个动作；语气比单用「たり」自然。所有动词都要变 た形 + り。

G4.〜た 後で〜后

Vた + 後で或Nの + 後で = "…之后"。

①昼ごはんを 食べた 後で、散歩します。吃完午饭散步。
②仕事の 後で、映画を 見ます。工作结束后看电影。
③シャワーを 浴びた 後で、寝ます。洗澡后睡。
「後で」vs「〜てから」：「後で」强调顺序；「てから」强调"必须先完成前者"。下课时间用「後で」。

練習

1. 变 た形

  1. 飲む →
  2. 起きる →
  3. 来る →
  4. 泳ぐ →
  5. 勉強する →
  6. 行く →
▸ 答案
① 飲んだ ② 起きた ③ 来た（きた）④ 泳いだ ⑤ 勉強した ⑥ 行った（例外）

2. 翻译

  1. 你骑过摩托车吗？
  2. 周末做做运动、买买东西之类。
  3. 吃完晚饭后看电视。
  4. 去过两次温泉。
▸ 答案
① バイクに 乗った ことが ありますか。
② 週末は 運動を したり、買い物を したり します。
③ 夕ご飯を 食べた 後で、テレビを 見ます。
④ 温泉に 二回 行った ことが あります。
