森さんはジョギングをしたことがあります

本课学用〜たことがあります表达过去的经历，以及「〜たり〜たりします」列举动作。

基本課文 CORE · 聊旅行经历

小野森さんは富士山に登ったことがありますか。森先生登过富士山吗？
森ええ、一度登ったことがあります。嗯，登过一次。
小野外国へ行ったことは？去过外国吗？
森フランスとドイツへ行ったことがあります。去过法国和德国。
小野ワンさんは？王先生呢？
ワン私はまだ日本しか行ったことがありません。我还只去过日本。

応用課文 EXTENDED · 周末安排

李吉田さん、週末は何をしますか。吉田，周末做什么？
吉田ジョギングをしたり、料理を作ったりします。跑跑步、做做饭之类的。
李温泉へ行ったことはありますか。去过温泉吗？
吉田はい、よく行きます。李さんも一緒にどうですか。去过，常去。李先生要不要一起？

文法

G1.动词た形た形

「た形」与「て形」变化规律完全相同，只需把「て→た、で→だ」。如 書く→書いた、食べる→食べた、来る→来た（きた）、する→した。

①昨日、公園を散歩した。昨天在公园散步了。
②朝ごはんを食べた。吃过早饭了。
③友達が来た。朋友来了。
た形是简体过去时，也是构成各种语法的基础形式。

G2.〜たことがあります经历

「動詞た形 + ことがあります」表示"有过……的经历"。否定用「〜たことがありません」。

①スカイダイビングをしたことがあります。我有过跳伞的经历。
②納豆を食べたことがありますか。你吃过纳豆吗？
③富士山に登ったことがありません。没登过富士山。
询问次数时用「〜回あります」，如「二回行ったことがあります」。

G3.〜たり、〜たりします列举

「動詞た形 + り」重复使用，最后加「します」，表示"做这做那"，列举若干动作（不穷举）。

①音楽を聴いたり、本を読んだりします。听听音乐、看看书之类的。
②週末は掃除をしたり、洗濯をしたりします。周末打扫打扫、洗洗衣服。
至少列举两个动作；语气比「〜たり〜たり」单用更自然。

G4.〜後で／〜あとで之后

「動詞た形 + 後で」或「名詞 の + 後で」表示"……之后"。

①昼ごはんを食べた後で、散歩します。吃完午饭之后散步。
②仕事の後で、映画を見ます。工作结束后看电影。
③シャワーを浴びた後で、寝ます。洗完澡后睡觉。
「後で」强调先后顺序；与「〜てから」意思相近但句型略有不同。

練習

1. 变た形

  1. 飲む →
  2. 起きる →
  3. 来る →
  4. 泳ぐ →
  5. 勉強する →
▸ 答案
飲んだ　起きた　来た（きた）　泳いだ　勉強した

2. 翻译

  1. 你骑过摩托车吗？
  2. 周末我做做运动、买买东西之类的。
  3. 吃完晚饭后看电视。
▸ 答案
① バイクに乗ったことがありますか。
② 週末は運動をしたり、買い物をしたりします。
③ 夕ご飯を食べた後で、テレビを見ます。
