基本課文 CORE · 年龄与身高

森李さんは何歳ですか。李，多大？
李二十五歳です。森さんは？二十五。森呢？
森三十二歳です。わたしのほうが年上です。三十二，我大。
李でも、森さんのほうが背が高いですね。不过你身高更高。
森そうですね。李さんはわたしより軽いでしょう。对。你比我轻吧。
李はい、わたしは森さんほど重くないです。是的，我没你重。
森スポーツは何が一番得意ですか。擅长哪项运动？
李サッカーです。森さんは？足球。森呢？
森わたしは水泳のほうが好きです。我更喜欢游泳。
李健康的ですね。很健康呢。

応用課文 EXTENDED · 选哪个

小野この鞄とあの鞄とどちらが軽いですか。这包和那包哪个轻？
李あの鞄のほうが軽いです。那个轻。
小野大きさはどうですか。大小呢？
李この鞄はあの鞄ほど大きくないです。这个没那个大。
小野どちらを 買いますか。买哪个？
李あの 軽いほうを 買います。买轻的那个。
森東京と 北京と、どちらが 人口が 多いですか。东京和北京哪个人口多？
李北京の ほうが 多いです。北京多。
森交通は どうですか。交通呢？
李どちらも 便利ですが、東京の ほうが 速いです。都方便，但东京更快。

文法

G1.Ａは Ｂより 形容词AはBより

A 比 B 更…，より 引出比较基准。形容词不变形。

①李さんは森さんより若いです。李比森年轻。
②この本はあの本より高いです。这本书比那本贵。
③東京は大阪より大きいです。东京比大阪大。
结构记忆："Ａは Ｂより ＿＿"。汉语"比"在前，日语「より」在后。

G2.Ａより Ｂのほうが 形容词AよりBのほう

强调 B 比 A 更…。语序颠倒时用 のほう。

①森さんより李さんのほうが若いです。比起森，李更年轻。
②電車よりバスのほうが遅いです。比起电车，公交更慢。
③夏より冬のほうが好きです。比起夏天，更喜欢冬天。
这个句型常用于回答「どちらが〜」。也常省略 A："冬の ほうが 好きです"。

G3.Ａは Ｂほど 形容词くないAはBほど〜ない

A 不如 B 那么…，必接否定。是日语典型的委婉表达。

①李さんは森さんほど重くないです。李没有森重。
②この部屋はあの部屋ほど広くないです。这个房间没那个房间宽。
③今日は昨日ほど寒くないです。今天没有昨天冷。
语义对比：「Ａは Ｂより 小さい」直白；「Ａは Ｂほど 大きくない」委婉，"不及"。和上司/前辈对话时多用后者。

G4.Ａと Ｂと どちらが 形容词ですかどちらが

两者相比"哪个更…"。どちら=哪个（二选一，礼貌），口语「どっち」。

①りんごとみかんとどちらが好きですか。苹果和橘子哪个更喜欢？
②電車とバスとどちらが速いですか。电车和公交哪个更快？
③この鞄とあの鞄とどちらが軽いですか。这个包和那个包哪个轻？
回答：用「Ｘの ほうが〜」。"两者都〜"答「どちらも〜」。三个以上选一用「どれ」。

練習

1. 用「より／ほど／のほうが」填空

  1. 東京は 大阪( ) 大きいです。
  2. バス( ) 電車( ) 速いです。
  3. 今日は 昨日( ) 寒くないです。
  4. りんごと みかんと どちら( ) 好きですか。
▸ 答案
① より　② より / のほうが　③ ほど　④ が

2. 翻译

  1. 这台电脑比那台贵。
  2. 比起音乐，更喜欢电影。
  3. 猫和狗哪个更可爱？
  4. 今天没有昨天忙。
▸ 答案
① このパソコンはあのパソコンより高いです。
② 音楽より映画のほうが好きです。
③ 猫と犬とどちらがかわいいですか。
④ 今日は 昨日ほど 忙しくないです。
