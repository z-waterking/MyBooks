文法

G1.普通体 + と 思いますと思う

普通体（简体）+ と 思います = "我认为〜"。否定时用「〜ないと 思う」，不是「〜と 思わない」（语感不同）。

①李さんは もうすぐ 来ると 思います。我觉得李快来了。
②明日は 雨が 降ると 思います。我想明天会下雨。
③日本料理は すばらしいと 思います。我觉得日本菜很棒。
第三人称的"持续的想法"用「〜と 思って います」：「森さんは 留学したいと 思って います」。

G2.普通体 + と 言いましたと言う

普通体 + と 言いました = "（某人）说〜"，转述。「と 言って いました」更口语，强调"曾说过"。

①課長は 午後から 出かけると 言いました。课长说下午要出门。
②天気予報は 雪が 降ると 言って いました。天气预报说会下雪。
③森さんは パーティーに 行くと 言いました。森说要去派对。
直接引用用「」「」：「彼は『また 明日』と 言いました」。

G3.〜んです（理由・説明）んです

普通体 + んです（ナ形/名词时为な + んです）= "是因为〜／（其实）〜"，表说明、原因。

①頭が 痛いんです。（其实）我头疼。
②お腹が いっぱいなんです。（因为）我饱了。
③東京タワーへ 行きたいんですが…我想去东京塔（请问怎么走）…
句末「〜が」是开场白常用法："〜んですが" 后续问路、求助、请求。不要滥用「んです」，会显得过于强调。

G4.Ｎ + についてについて

Ｎ + について = "关于〜"，引出话题。后续常配「思う／話す／書く／聞く／知る」等。

①日本の 文化に ついて 話しましょう。聊聊日本文化吧。
②この 問題に ついて どう 思いますか。关于这个问题怎么看？
③歴史に ついての 本を 読みました。看了关于历史的书。
书面常用「に関して」更正式。「についての + 名词」可作定语：「歴史についての 本」。

練習

1. 用「と 思います」改写

  1. 李さんは 来ます。→
  2. 明日は 暑いです。→
  3. 日本語は 難しいです。→
▸ 答案
① 李さんは 来ると 思います。
② 明日は 暑いと 思います。
③ 日本語は 難しいと 思います。

2. 翻译

  1. 老师说今天有考试。
  2. 我觉得这部电影很棒。
  3. 想去东京塔，怎么走？
  4. 关于日本文化你怎么看？
▸ 答案
① 先生は 今日 試験が あると 言いました。
② この 映画は すばらしいと 思います。
③ 東京タワーへ 行きたいんですが、どうやって 行きますか。
④ 日本の 文化に ついて、どう 思いますか。
