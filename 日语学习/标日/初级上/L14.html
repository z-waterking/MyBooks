基本課文 CORE · 昨天去哪了

森李さん、昨日どこへ行きましたか。李，昨天去哪了？
李デパートへ行きました。買い物をしました。去了百货店，购了物。
森何を買いましたか。买了什么？
李セーターを一枚買いました。买了一件毛衣。
森先週の日曜日は？上周日呢？
李どこも行きませんでした。家で休みました。哪里也没去，在家休息了。
森誰にも 会いませんでしたか。没见到谁吗？
李はい、ずっと 一人でした。对，一直一个人。
森大変でしたね。今度の 連休に 一緒に 散歩 しませんか。挺累的。下次连休一起散步吧？
李いいですね、ぜひ。好啊，一定。

応用課文 EXTENDED · 周末做了什么

李吉田課長、原稿が できました。吉田课长，原稿写好了。
吉田箱根の 記事ですね。ちょっと 見せて ください。箱根那篇吧。给我看看。
吉田なかなか いいですね。いつ 書きましたか。不错。什么时候写的？
李昨日 会社で メモを 整理して、小野さんに 見せました。昨天在公司整理了笔记，给小野看了。
李そして、アパートへ 帰ってから 書きました。然后回公寓后写完的。
吉田そうですか。大変でしたね。写真は できましたか。这样啊，挺辛苦的。照片好了吗？
李はい、これから 長島さんの 事務所へ 行って、写真を 選びます。是的，接下来去长岛事务所选照片。
吉田そうですか。手早く 進めましょう。嗯，加快进度吧。
李後で 写真を 見て くださいませんか。稍后能帮我看看照片吗？
吉田李さん、もう 会社を 出ますか。李，要离开公司了吗？
李はい、銀行に お金を 下ろしてから、行きます。是的，先去银行取钱然后过去。
吉田じゃあ、郵便局の 近くを 通りますね。那你会经过邮局附近吧。
吉田すみませんが、この 手紙を 出して ください。麻烦把这封信寄出去。
李はい。速達で 出しますか。好。寄快递吗？
吉田ええ、そうして ください。嗯，那样吧。

文法

G1.Ｖます → Ｖました（过去肯定）过去肯定

动词「ます」体过去肯定 = 「ます → ました」。

①昨日デパートへ行きました。昨天去了百货店。
②先週日本語を勉強しました。上周学了日语。
③セーターを一枚買いました。买了一件毛衣。
复习 L05：四种活用 ます／ません／ました／ませんでした。

G2.Ｖません → Ｖませんでした（过去否定）过去否定

过去否定 = 「ません → ませんでした」。结构对称。

①昨日どこも行きませんでした。昨天哪里也没去。
②朝ご飯を食べませんでした。没有吃早饭。
③宿題を忘れませんでした。没有忘记作业。
常见错误：不能说「行きませんました」。必须「ませんでした」整体。

G3.疑问词も + 否定（全否定）全否定

どこも・何も・だれも・いつも ＋ 否定动词 = "哪里也/什么也/谁也/总也…不…"。

①どこも行きませんでした。哪里也没去。
②何も食べませんでした。什么也没吃。
③だれも来ませんでした。谁也没来。
④だれにも会いませんでした。谁也没见到。
含助词的"全否定"要保留助词：「だれにも会いません」（谁也没遇见）、「どこでも食べません」（哪儿也不吃）。

G4.時間詞 + は（话题化）时间は

把时间词放句首加「は」，是对比性话题化，强调"这一时间段(相对其他时间)的情况"。

①昨日はデパートへ行きました。昨天（去了/不像其他天）去了百货店。
②先週はどこも行きませんでした。上周哪里也没去。
③週末は 家で 休みます。周末（不同于平日）在家休息。
不加「は」也对，但话题化能暗示对比：「平日は 忙しいですが、土曜日は 暇です」。

練習

1. 变过去时

  1. 毎日 日本語を 勉強します。→（过去肯定）
  2. 週末は どこも 行きません。→（过去否定）
  3. 友達に 電話を します。→（过去肯定）
  4. だれも 来ません。→（过去否定）
▸ 答案
① 毎日 日本語を 勉強しました。
② 週末は どこも 行きませんでした。
③ 友達に 電話を しました。
④ だれも 来ませんでした。

2. 翻译

  1. 上个月去了东京。
  2. 昨天没有吃午饭。
  3. 上周哪里也没出去。
  4. 昨天谁也没见到。
▸ 答案
① 先月東京へ行きました。
② 昨日昼ご飯を食べませんでした。
③ 先週はどこも出かけませんでした。
④ 昨日 だれにも 会いませんでした。
