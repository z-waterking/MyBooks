第 9 課 · LESSON NINE · イ形容詞

四川料理は辛いです

日语形容词分两类。本课学第一类——イ形容词（以「い」结尾）。掌握其肯定、否定、连用形。学会"～くて"做并列，"～が、～"做转折。

基本課文 CORE · 谈论饭菜

森李さん、どんな料理が好きですか。李喜欢什么样的菜？
李四川料理が好きです。とてもおいしいですよ。喜欢四川菜。很好吃。
森四川料理は辛いですか。四川菜辣吗？
李ええ、とても辛いです。でもおいしいです。嗯，非常辣。但是好吃。
森日本料理はどうですか。日本料理怎么样？
李あまり辛くないですが、おいしいです。不太辣，但好吃。

応用課文 EXTENDED · 谈论旅行

小野先週の旅行はどうでしたか。上周的旅行怎么样？
李楽しかったです。京都はとても古くて美しい町でした。很愉快。京都是又古老又美的城市。
小野天気はよかったですか。天气好吗？
李いいえ、あまりよくありませんでした。少し寒かったです。不，不太好。有点冷。
小野ホテルはどうでしたか。酒店怎么样？
李広くて新しかったです。とてもよかったです。又宽敞又新，非常好。

文法

G1.名 は イ形容詞 です肯定

イ形容词以「い」结尾，直接接「です」（不需要中间词）。

①この本は面白いです。这本书有趣。
②日本語は難しいです。日语难。
③今日は寒いです。今天冷。

G2.イ形容詞 的活用否定 / 过去

把词尾「い」改成「く」即可接否定 / 过去：

时态辛い → ?
现在肯定辛いです
现在否定辛くないです / 辛くありません
过去肯定辛かったです
过去否定辛くなかったです
①この料理は辛くないです。这道菜不辣。
②昨日は寒かったです。昨天冷。
③天気はよくなかったです。天气不好。
例外：「いい」（好）的变形要用「よい」做基础：よくない / よかった / よくなかった。不能说"いくない"。

G3.イ形容詞 + 名词连体修饰

イ形容词修饰名词时，保留「い」直接接名词，不变形。

①新しい本を買いました。买了新书。
②大きい部屋がほしいです。想要大房间。
③面白い映画を見ました。看了有趣的电影。

G4.～くて、～并列

イ形容词的连用形，把「い」→「くて」，用来连接两个形容词（褒褒、贬贬 OK；褒贬交替用「が」转折）。

①この部屋は広くて明るいです。这房间又宽敞又明亮。
②この料理は安くておいしいです。这道菜便宜又好吃。
③この本は厚いですが、面白いです。这本书虽然厚但有趣。
褒贬转换："贵但是好" → 高いですが、いいです（用「が」转折），不能说"高くていいです"。

練習

1. イ形容词变形

  1. 大きい → 否定 ___
  2. 寒い → 过去 ___
  3. 面白い → 过去否定 ___
  4. いい → 否定 ___
▸ 答案
① 大きくないです ② 寒かったです ③ 面白くなかったです ④ よくないです（不是 いくない）

2. 翻译

  1. 这家餐厅又便宜又好吃。
  2. 昨天的天气不好。
  3. 日语难，但是有趣。
  4. 我想要新的、小的相机。
▸ 答案
① このレストランは安くておいしいです。
② 昨日の天気はよくなかったです。
③ 日本語は難しいですが、面白いです。
④ 新しくて小さいカメラがほしいです。
