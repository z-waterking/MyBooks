基本課文 CORE · 聊吃过没吃过

甲わたしは すき焼きを 食べた ことが あります。我吃过寿喜烧。
甲李さんは 会社が 終わった 後で、飲みに 行きます。李下班后去喝酒。
甲もっと 野菜を 食べた ほうが いいです。最好多吃点蔬菜。
甲窓を 閉めましょうか。要不要把窗户关上？
甲お寿司を 食べた ことが ありますか。吃过寿司吗？
乙いいえ、一度も ありません。没，一次也没有。
甲天ぷらは 食べた ことが あります。天妇罗倒是吃过。
甲この 資料を 見ても いいですか。可以看这份资料吗？
乙はい、読んだ 後で、森さんに 渡して ください。嗯，看完后交给森。
甲ホテルを 予約した ほうが いいですか。是不是该订酒店？
乙そうですね。連休ですから、早めに 予約した ほうが いいですね。对啊，连休所以早点订好。
甲何か 食べましょうか。要不要吃点什么？
乙いいえ、寝る 前に 食べない ほうが いいですよ。不，睡前不吃比较好。

応用課文 EXTENDED · 参观歌舞伎

小野少し 急ぎましょうか。遅れない ほうが いいですから。稍微赶一下吧，最好别迟到。
李そうしましょう。ところで、小野さんは よく 歌舞伎を 見ますか。那就走快点。对了，小野你常看歌舞伎吗？
小野仕事の 後で、何度か 見に 行った ことが あります。工作之后去看过几次。
李歌舞伎は 見た 後で、食べますか。それとも、何か 食べてから 行きましょうか。歌舞伎是看完后吃饭，还是先吃点再去？
小野歌舞伎は 9時ごろですね。食事は どうしましょうか。歌舞伎大概到 9 点。吃饭怎么安排？
李休憩時間に 食べた ほうが いいです。中场休息时吃比较好。
小野そうですね、休憩時間に 食事を しましょう。对，那就中场时吃。
小野じゃあ、早く 行って、お弁当を 買った ほうが いいですね。那早点去买便当吧。
李言葉は 分かりませんでしたが、とても よかったです。台词没听懂，但很棒。
小野そうですね。課長に 感謝しましょう。是啊，得感谢课长。
李ええ、京劇も いいですが、歌舞伎も すばらしいですね。嗯，京剧好，歌舞伎也很棒。
小野李さんは 京劇を 見た ことが ありますか。李你看过京剧吗？
李いいえ、一度も ありません。いつか 見たいですね。没，从来没有。哪天想看看。
小野じゃあ、ぜひ 北京へ 京劇を 見に 来て ください。那务必来北京看京剧。

文法

G1.動詞た形た形

た形变化和て形完全相同，只把「て→た／で→だ」。是简体过去式，也是后续语法的基础。

①書く → 書いたV1: く → いた
②読む → 読んだV1: む → んだ
③食べる → 食べたV2: る → た
④する → した／来る → 来たV3 不规则
例外：行く → 行った（不是「行いた」）。と形变化口诀复习：く→いた、ぐ→いだ、む/ぶ/ぬ→んだ、つ/る/う→った、す→した。

G2.Ｖた ことが あります経験

Ｖた形 + ことが あります = "有过…的经历"。否定「〜た ことが ありません」。

①すき焼きを 食べた ことが あります。吃过寿喜烧。
②歌舞伎を 見た ことが あります。看过歌舞伎。
③一度も 行った ことが ありません。一次也没去过。
问次数用「何回」：「何回 行った ことが ありますか」→「三回 行った ことが あります」。

G3.Ｖた ほうが いい建议

Ｖた形 + ほうが いいです = "最好做〜"，给对方建议。否定用「〜ない ほうが いい」。

①早く 寝た ほうが いいです。最好早睡。
②ホテルを 予約した ほうが いいです。最好订酒店。
③寝る 前に 食べない ほうが いいです。睡前最好不要吃。
肯定用た形，否定用ない形，不要写成「食べる ほうが いい」（一般场合）。

G4.Ｖましょうか提议帮忙

Ｖます形（去ます）+ ましょうか = "我（我们）来〜吧？"，提议主动做某事。

①窓を 閉めましょうか。要把窗户关上吗？
②荷物を 持ちましょうか。行李我来拿吧？
③何か 食べましょうか。要不要吃点什么？
「ましょう」vs「ましょうか」：「ましょう」是单方决定"一起做吧"；「ましょうか」是征求对方意见，更礼貌。

練習

1. 变 た形

  1. 食べる →
  2. 行く →
  3. 飲む →
  4. 来る →
  5. 見る →
  6. 泳ぐ →
▸ 答案
① 食べた ② 行った（例外）③ 飲んだ ④ 来た（きた）⑤ 見た ⑥ 泳いだ

2. 翻译

  1. 你吃过寿司吗？
  2. 最好多喝水。
  3. 行李我来拿吧？
  4. 看完后请交给森。
▸ 答案
① お寿司を 食べた ことが ありますか。
② もっと 水を 飲んだ ほうが いいです。
③ 荷物を 持ちましょうか。
④ 見た 後で、森さんに 渡して ください。
