基本課文 CORE · 聊语言能力

森ワンさんは日本語を話せますか。王能说日语吗？
ワンええ、少し話せます。嗯，能说一点。
森新聞も読めますか。报纸也能读吗？
ワン簡単な記事なら読めます。简单的报道能读。
森漢字は書けますか。汉字能写吗？
ワン難しい字はあまり書けません。难的写不好。
森英語は どうですか。英语呢？
ワン英語は 全然 できません。英语完全不行。
森でも、中国語は できますね。不过中文会吧。
ワンもちろん、母語ですから。当然，母语嘛。

応用課文 EXTENDED · 点单不行

李この店、英語のメニューはありますか。这店有英文菜单吗？
店員すみません、日本語しかありません。抱歉，只有日语。
李じゃ、注文できません。森さん、お願いします。那点不了，森拜托了。
森わかりました。何にしますか。好的，要什么？
李刺身が 食べられますか。能吃生鱼片吗？
森もちろん。寿司も 大丈夫です。当然，寿司也可以。
李じゃ、お任せで お願いします。那就交给你了。
森店員さん、お任せで お願いします。店员，请来个推荐。
店員かしこまりました。好的。
李ありがとう、森さん。谢谢，森。

文法

G1.1类（V1）可能形：う段→え段+るV1可能

五段动词把词尾「う段」改为「え段」，加「る」（属于 V2）。

原形可能形
話す話せる
書く書ける
読む読める
飲む飲める
買う買える
泳ぐ泳げる
①日本語が話せます。能说日语。
②簡単な漢字が書けます。简单的汉字能写。
③海で泳げますか。能在海里游泳吗？
可能形对象用「が」，不用「を」：「日本語が 話せます」。原"を"句变可能形时通常换成"が"。

G2.2类（V2）可能形：る→られるV2可能

一段动词去「る」加「られる」。

①刺身が食べられます。能吃刺身。
②字幕なしで映画が見られます。不看字幕能看电影。
③朝 早く 起きられます。能早起。
口语「ら抜き言葉」：「食べられる → 食べれる」「見られる → 見れる」，年轻人常用，但正式场合仍保留「ら」。

G3.不规则：来る→来られる、する→できるV3可能

来る → 来られる（こられる）；する → できる。

①明日は来られます。明天能来。
②ピアノが できます。会弹钢琴。
③運転が できません。不会开车。
「できる」非常常用，同时也用于「名词 + が できる」句型（L20）。

G4.〜しか + 否定只…

〜しか + 否定 = "只…"（含"不够"语感）。比「だけ」更强。

①日本語しか話せません。只能说日语。
②千円しかありません。只有 1000 日元。
③一人しか 来ませんでした。只来了一个人。
「だけ」vs「しか〜ない」：「だけ」客观陈述"仅限"；「しか〜ない」带"嫌少"的主观感。

練習

1. 变可能形

  1. 書く →
  2. 食べる →
  3. 来る →
  4. する →
  5. 泳ぐ →
  6. 飲む →
▸ 答案
① 書ける ② 食べられる ③ 来られる（こられる）④ できる ⑤ 泳げる ⑥ 飲める

2. 翻译

  1. 我能读简单的日语。
  2. 弟弟会弹钢琴。
  3. 今天只能喝水。
  4. 法语完全不会。
▸ 答案
① 簡単な 日本語が 読めます。
② 弟は ピアノが できます。
③ 今日は 水しか 飲めません。
④ フランス語は 全然 できません。
