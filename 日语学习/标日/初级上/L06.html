吉田さんは 来月 中国へ 行きます

本课学移动动词「行きます／来ます／帰ります」，助词 へ（方向）和 で（交通工具），以及共同动作的 と。

基本課文 CORE · 出差与归国

甲吉田さんは 来月 中国へ 行きます。吉田下月去中国。
甲この スーパーは 9時から 9時までです。这家超市从9点到9点。
甲わたしは 毎日 タクシーで 会社へ 行きます。我每天打车去公司。
甲森さんは 家族と 北京へ 来ました。森和家人来了北京。
甲どこへ 行きますか。去哪里？
乙銀行へ 行きます。去银行。
甲何で 来ましたか。怎么来的？
乙電車で 来ました。坐电车来的。
甲だれと 帰りますか。和谁一起回？
乙一人で 帰ります。一个人回。

応用課文 EXTENDED · 周末出行

小野李さん、土曜日は どこかへ 行きますか。李，周六去哪里吗？
李ええ、家族と 横浜へ 行きます。嗯，和家人去横滨。
小野何で 行きますか。怎么去？
李電車で 行きます。坐电车去。
小野いいですね。不错呢。
吉田森君、来月 国へ 帰りますか。森君，下个月回国吗？
森いいえ、帰りません。再来月 出張で 上海へ 行きます。不，不回。下下个月因公出差去上海。
吉田そうですか。気を つけて。这样啊，路上小心。
森ありがとうございます。谢谢。

文法

G1.Ｎ(场所) へ 行きます／来ます／帰ります方向へ

へ（读 /e/）标示移动的方向。常用三个移动动词搭配。

①東京へ 行きます。去东京。
②日本へ 来ました。来日本了。
③国へ 帰ります。回国。
「へ」vs「に」：表方向时基本可互换；「に」更强调到达点，「へ」更强调方向。初学先用「へ」即可。「へ」作助词时读 /e/，不读 /he/。

G2.Ｎ(交通工具) で 行きます手段で

で表示动作的方式或工具。乘车交通工具用「で」。

①バスで 学校へ 行きます。坐公交去学校。
②新幹線で 大阪へ 行きました。坐新干线去了大阪。
③自転車で 来ました。骑自行车来的。
步行不用「で」：是「歩いて 行きます」（走着去）。问"怎么去"用「何で 行きますか」（なん为多）。

G3.Ｎ と 行きます／来ます共同と

と表示共同动作的对象，相当于"和谁一起"。

①友達と 映画を 見ました。和朋友看了电影。
②家族と 旅行します。和家人去旅行。
③だれと 食べますか。和谁一起吃？
"一个人"用「一人で」，用「で」不用「と」。

G4.いつ／どこ／だれ／何 + ますか基本疑问词

日语 5W1H 与「ます」体疑问句搭配，语序与陈述句相同，仅替换疑问对应的成分。

①いつ 日本へ 行きますか。什么时候去日本？
②どこで 食べますか。在哪里吃？
③何で 来ましたか。怎么来的？
回答疑问词的句子用「が」不用「は」："だれが 来ましたか" → "森さんが 来ました"。

練習

1. 助词填空

  1. わたしは バス( ) 会社( ) 行きます。
  2. 友達( ) 映画( ) 見ました。
  3. 何( ) 大阪( ) 行きますか。
  4. 一人( ) 帰ります。
▸ 答案
① で / へ ② と / を ③ で / へ ④ で

2. 翻译

  1. 我每天坐电车去公司。
  2. 森下个月和家人去中国。
  3. 昨天和朋友走着去了公园。
  4. 一个人回家。
▸ 答案
① わたしは 毎日 電車で 会社へ 行きます。
② 森さんは 来月 家族と 中国へ 行きます。
③ 昨日 友達と 歩いて 公園へ 行きました。
④ 一人で 家へ 帰ります。
