基本課文 CORE · 聊日常习惯

小野李さん、休みの日はいつも何をしますか。李，休息日通常做什么？
李掃除をしたり、洗濯をしたりします。打扫、洗衣之类。
小野暇なとき、散歩しますか。有空时散步吗？
李ええ、音楽を聴きながら散歩します。嗯，边听音乐边散步。
小野出かける前に何かしますか。出门前做什么？
李ストレッチをしてから出かけます。做完伸展再出门。
小野寝る 前に 何を しますか。睡前做什么？
李日記を 書きながら 一日を 振り返ります。边写日记边回顾一天。
小野健康的ですね。很健康。
李小野さんも 一緒に どうですか。小野也一起？

応用課文 EXTENDED · 边走边聊

吉田太郎、スマホを見ながら歩かないで。太郎，别边走边看手机。
太郎わかった。あ、財布を忘れた。知道了。啊，忘带钱包了。
吉田出かける前に確認しなきゃ。出门前要确认啊。
太郎寝る前に準備しておけばよかった。早知道睡前就准备好了。
吉田シャワーを 浴びてから 出よう。洗完澡再出门吧。
太郎時間が ないよ。没时间了。
吉田遅刻する とき、急ぐと もっと 危ない。要迟到的时候急更危险。
太郎わかった、落ち着く。知道了，冷静。
吉田歯を 磨いてから 行こう。刷完牙再走。
太郎うん。嗯。

文法

G1.〜ときとき

とき前接动词辞书形/た形、形容词、名词の，表"…的时候"。辞书形=动作未发生；た形=已完成。

①暇なとき、音楽を聴きます。有空时听音乐。
②日本へ 来たとき、とても 緊張しました。来日本时非常紧张。
③困ったとき、先生に 聞いて ください。困难时请问老师。
注意时态：主句先于从句用「た形 + とき」；同时或主句在后用「辞書形 + とき」。

G2.〜ながらながら

Vます形（去ます） + ながら = "一边…一边…"。主动作在后半句。

①音楽を 聴きながら 勉強します。边听音乐边学习。
②コーヒーを 飲みながら 新聞を 読みます。边喝咖啡边看报。
③歩きながら 話しましょう。边走边聊吧。
「ながら」前后主语必须相同。"A 一边〜B 一边〜"（不同主语）要用别的句型。

G3.〜前に前に

V辞書形 / Nの + 前に = "…之前"。动词始终用辞书形，不变时态。

①寝る 前に、歯を 磨きます。睡前刷牙。
②試験の 前に、よく 復習して ください。考前请好好复习。
③出かける 前に 鍵を 確認します。出门前确认钥匙。
易错：「寝た 前に」错误！「前に」只能配辞书形，不能用た形。与「後で」（た形）对比记忆。

G4.〜てからてから

Vて + から = "做完…再…"，强调先后顺序与完成感。

①手を 洗ってから、ご飯を 食べます。洗完手吃饭。
②宿題を してから、ゲームを します。做完作业打游戏。
③シャワーを 浴びてから 寝ます。洗完澡睡。
「てから」vs「後で」：「てから」必须先完成前者；「後で」只表顺序，未必紧接。

練習

1. 填空（とき/ながら/前に/てから）

  1. 音楽を 聴き( ) 走ります。
  2. 日本に 来た( ) 富士山を 見ました。
  3. 寝る( ) 日記を 書きます。
  4. 準備を し( ) 出発します。
▸ 答案
① ながら ② とき ③ 前に ④ てから

2. 翻译

  1. 有空时我看看书。
  2. 请洗完手再吃。
  3. 我边听音乐边做饭。
  4. 出门前要确认钥匙。
▸ 答案
① 暇な とき、本を 読みます。
② 手を 洗ってから 食べて ください。
③ 音楽を 聴きながら 料理を します。
④ 出かける 前に 鍵を 確認します。
