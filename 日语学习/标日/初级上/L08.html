基本課文 CORE · 写信场景

小野李さん、何を書いていますか。李，在写什么？
李日本語で家族に手紙を書きます。用日语给家人写信。
小野日本語で？すごいですね。用日语？真厉害。
李いいえ、まだまだです。森さんに日本語を教えてもらいます。不，还差得远。森教我日语。
小野わたしも中国語を習いたいです。我也想学中文。
李じゃ、わたしが教えますよ。那我教你吧。

応用課文 EXTENDED · 生日礼物

森明日は小野さんの誕生日ですね。明天是小野的生日吧。
李そうですね。何かプレゼントをあげますか。是啊。送什么礼物呢？
森小野さんに花をあげます。李さんは何をあげますか。送花。李送什么？
李中国から本をもらいました。それを小野さんにあげます。从中国收到一本书，送给小野。
森いいですね。喜びますよ。真好，她会高兴的。

文法

G1.名 で 動詞工具 / 手段 / 语言

「で」表示用什么做某事——工具、材料、语言、电话/邮件等手段。

①日本語で話します。用日语说。
②箸でご飯を食べます。用筷子吃饭。
③メールで連絡します。用邮件联系。
「で」总结：L06 学了"交通工具で"，L07 学了"场所で（动作）"，本课"工具/手段で"——这三种用法都用同一个「で」。

G2.人 に 動詞动作对象

「に」标记动作的接受方，常用于"写信、打电话、教、给"等动作。

①友達に手紙を書きます。给朋友写信。
②先生に電話をかけます。给老师打电话。
③妹に日本語を教えます。教妹妹日语。

G3.人 に 名 を あげます / もらいます给与 / 接受

あげる（给出）：A は Bに 名 を あげます
もらう（接受）：A は Bに / から 名 を もらいます

①小野さんに花をあげます。送花给小野。
②森さんに本をもらいました。从森那里收到一本书。
③クリスマスに友達からプレゼントをもらいます。圣诞节从朋友那里收到礼物。
立场敏感：「あげる」不可对自己或自己的家人；要对自己人用「くれる」（后面课会学）。"妈妈给我礼物" 是 「母がくれます」不是 「母があげます」。

G4.もう／まだ完成 / 未完成

もう + 动词过去式 = 已经...了
まだ + 动词否定 = 还没...

①もう手紙を書きました。已经写完信了。
②まだ食べていません。还没吃。
③もう昼ご飯を食べましたか。已经吃午饭了吗？

練習

1. 选合适的助词

  1. 日本語 ___ 手紙を書きます。
  2. 友達 ___ プレゼントをあげます。
  3. 母 ___ 本をもらいました。
  4. 箸 ___ ご飯を食べます。
▸ 答案
① で ② に ③ に (또는 から) ④ で

2. 翻译

  1. 用英语给老师写信。
  2. 朋友送给我书。
  3. 已经打过电话了。
  4. 还没学中文。
▸ 答案
① 英語で先生に手紙を書きます。
② 友達に本をもらいました。
③ もう電話をかけました。
④ まだ中国語を習っていません。
