基本課文 CORE · 送礼与收礼

甲李さんは 日本語で 手紙を 書きます。李用日语写信。
甲わたしは 小野さんに 花を あげます。我送花给小野。
甲わたしは 小野さんに お土産を もらいました。我从小野那里收到了特产。
甲李さんは 森さんに 中国語を 教えます。李教森中文。
甲何で 食べますか。用什么吃？
乙箸で 食べます。用筷子吃。
甲だれに プレゼントを あげますか。送礼物给谁？
乙彼女に あげます。送给女朋友。
甲だれに もらいましたか。从谁那儿收到的？
乙父に もらいました。父亲给的。

応用課文 EXTENDED · 生日礼物

小野さっき 長島さんに 電話を もらいました。刚才接到长岛的电话。
李スケジュール表の 件ですか。是日程表的事吗？
小野はい。是。
李もう ファクスで 送りましたよ。已经发传真过去了。
小野いつですか。什么时候？
李昨日の 夕方です。昨天傍晚。
小野もう 一度 送りますか。要再发一次吗？
李ええ、お願いします。わたしは メールで 送ります。嗯，麻烦了。我也用邮件发一份。
小野分かりました。好的。
小野李さん、たった 今 長島さんに メールを もらいました。李，刚刚收到长岛的邮件。
李ファクスは 届きましたか。传真到了吗？
小野ええ、ファクスも メールも 届きました。嗯，传真和邮件都到了。
李そうですか。よかったです。那就好。
小野李さん、これ、どうぞ。前に 長島さんに もらいました。箱根の 写真集です。李这个给你。之前长岛给我的。是箱根的影集。
李ありがとうございます。谢谢。

文法

G1.Ｎ(工具/手段) で手段で

で 表示手段、工具、语言、材料。"用〜"。

①箸で 食べます。用筷子吃。
②日本語で 話します。用日语说。
③メールで 送ります。用邮件发送。
之前学过「で」表场所（动作场所）和手段，都用「で」，不矛盾——靠语境区分。

G2.Ａは Ｂに 〜を あげます给（出方视角）

あげます = "（我/某人）给（某人）某物"。に 标示接收方。

①わたしは 母に 花を あげました。我送花给妈妈。
②森さんは 李さんに 本を あげます。森给李一本书。
③だれに あげますか。送给谁？
禁忌：「お父さん／先生」给我东西不用「あげます」（不敬），要用「くださいます」。

G3.Ａは Ｂに 〜を もらいます收（收方视角）

もらいます = "（我/某人）从（某人）那里收到某物"。に（或「から」）标示给方。

①わたしは 友達に プレゼントを もらいました。我收到了朋友的礼物。
②森さんは 母から 手紙を もらいました。森收到母亲的信。
③だれに もらいましたか。从谁那儿得到的？
给方除了「に」也可用「から」，意思相同；公司/学校等机构来源更倾向「から」。

G4.Ａは Ｂに 〜を 教えます／習います教与学

教えます＝教；習います＝学（向某人学）。に 是对象/来源。

①森さんは 李さんに 日本語を 教えます。森教李日语。
②わたしは 母に 料理を 習いました。我向妈妈学了做菜。
③だれに 中国語を 習いましたか。向谁学的中文？
「習います」vs「勉強します」：「習います」强调"跟某人学"（有老师）；「勉強します」是自学/学习行为本身。

練習

1. 助词填空

  1. わたしは 母( ) 花( ) あげました。
  2. 森さんは 友達( ) お土産( ) もらいました。
  3. 李さんは 日本語( ) 手紙( ) 書きます。
  4. だれ( ) 中国語( ) 習いましたか。
▸ 答案
① に / を ② に（から）/ を ③ で / を ④ に / を

2. 翻译

  1. 用筷子吃饭。
  2. 我送了一束花给妈妈。
  3. 我从森那儿收到了字典。
  4. 李教森中文。
▸ 答案
① 箸で ご飯を 食べます。
② わたしは 母に 花束を あげました。
③ わたしは 森さんに 辞書を もらいました。
④ 李さんは 森さんに 中国語を 教えます。

3. 听写挑战

  1. 留意「に」的双重含义：给方还是收方，靠动词区分。
