基本課文 CORE DIALOGUE · 日常作息

李森さんは毎日何時に起きますか。森先生每天几点起床？
森毎朝七時に起きます。每天早上七点起床。
李仕事は何時から何時までですか。工作从几点到几点？
森九時から六時までです。从九点到六点。
李土曜日も働きますか。星期六也工作吗？
森いいえ、土曜日と日曜日は休みます。不，星期六和星期日休息。

応用課文 EXTENDED · 周末计划

小野李さん、日曜日は何をしますか。李，星期日做什么？
李いつも午前は勉強します。そして午後は休みます。总是上午学习，下午休息。
小野何時から何時まで勉強しますか。从几点学到几点？
李九時から十二時までです。从九点到十二点。
小野時々わたしも一緒に勉強しませんか。有时我也一起学习好吗？

文法 GRAMMAR · 4 points

G1.動詞「ます」形现在 / 将来

日语动词在礼貌体中以「～ます」结尾。「ます」表示：1) 现在的习惯（"每天起床"）；2) 将来的动作（"明天去"）。

否定：「～ません」；疑问：「～ますか」。

①毎日働きます。每天工作。
②日曜日は勉強しません。星期日不学习。
③李さんは毎朝何時に起きますか。李每天早上几点起床？

G2.時間 に 動詞时间点

具体的"时间点"（几点、星期几、日期）用助词「に」。例外：「今日 / 明日 / 昨日 / 朝 / 夜 / いつも」等不带「に」。

①毎日六時に起きます。每天六点起床。
②月曜日に会議があります。星期一有会议。
③今日働きます。今天工作。
记忆："数字相关 + 星期日期" → 加「に」；"今天/昨天/早晨"等概念性时间 → 不加。

G3.～から～まで从…到…

「から」起点，「まで」终点。可用于时间（几点到几点）或场所（哪里到哪里）。

①会議は二時から四時までです。会议从两点到四点。
②月曜日から金曜日まで働きます。从星期一工作到星期五。
③家から会社まで遠いです。从家到公司很远。

G4.動詞 + ませんか邀请

「～ませんか」字面是否定疑问，实际意为"要不要一起…？"，是日语最常用的邀请句型。

①一緒に勉強しませんか。一起学习好吗？
②日曜日に映画を見ませんか。星期日去看电影吗？
③時々一緒に休みませんか。有时一起休息吗？
对比：「～ましょう」（让我们…吧）比「ませんか」语气更主动。两者常配合使用："見ませんか？" — "ええ、見ましょう！"

練習

1. 填入合适的助词（に / から / まで / は / が / を）

  1. 毎日七時 ___ 起きます。
  2. 九時 ___ 六時 ___ 働きます。
  3. 土曜日 ___ 休みます。
  4. 森さん ___ 毎日勉強します。
▸ 答案
① に ② から、まで ③ は（强调对比） ④ は

2. 翻译

  1. 我每天早上六点起床。
  2. 工作从九点到六点。
  3. 星期日不学习。
  4. 下星期一起去看电影好吗？
▸ 答案
① わたしは毎朝六時に起きます。
② 仕事は九時から六時までです。
③ 日曜日は勉強しません。
④ 来週の月曜日に一緒に映画を見ませんか。
