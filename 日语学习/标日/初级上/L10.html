基本課文 CORE · 评价人事物

甲京都の 紅葉は 有名です。京都的红叶很有名。
甲奈良は 静かな 町です。奈良是个安静的城市。
甲あの 人は あまり 親切では ありません。那个人不太亲切。
甲昨日は 暇でした。昨天有空。
甲去年の 旅行は あまり 楽でなかったです。去年的旅行不太轻松。
甲京都は どんな 町ですか。京都是个什么样的城市？
乙きれいな 町です。是个漂亮的城市。
甲あの 先生は 親切ですか。那位老师亲切吗？
乙はい、とても 親切です。是的，非常亲切。
甲昨日は 暇でしたか。昨天有空吗？
乙いいえ、暇じゃ ありませんでした。不，没空。

応用課文 EXTENDED · 京都印象

小野李さん、京都は どうでしたか。李，京都怎么样？
李とても きれいでした。お寺も 公園も 立派でした。非常漂亮。寺庙、公园都很气派。
小野町は にぎやかでしたか。城市热闹吗？
李いいえ、思ったより 静かでした。でも、人は とても 親切でした。不，比想象的安静。不过人非常亲切。
小野有名な 場所は どこですか。有名的地方在哪里？
李清水寺と 金閣寺です。観光客が 多くて、にぎやかでした。清水寺和金阁寺。游客很多，很热闹。
小野それは 大変でしたね。那挺累的吧。
李ええ、でも 紅葉が きれいで、いい 思い出に なりました。是啊，不过红叶很美，留下了好回忆。
小野今度 わたしも 行きたいです。下次我也想去。
李秋が 一番 いい 季節ですよ。秋天是最好的季节哦。

文法

G1.ナ形容词の現在形：〜です／〜では ありません现在 肯否

ナ形容词的否定为「〜では／じゃ ありません」。"じゃ"是口语缩约形。

①元気です → 元気では ありません有精神 → 没精神
②好きです → 好きじゃ ありません喜欢 → 不喜欢
③静かです → 静かじゃ ないです安静 → 不安静（口语）
ナ形容词的肯否定形跟名词句一样——它本质是"名词+です"的派生。

G2.ナ形容词の過去形：〜でした／〜では ありませんでした过去 肯否

过去肯定：〜でした。过去否定：〜では／じゃ ありませんでした。

肯定否定
现在〜です〜では ありません
过去〜でした〜では ありませんでした
①元気でした（有精神）过去肯定
②暇では ありませんでした（没空）过去否定
③好きじゃ なかったです（不喜欢）过去否定（口语）
对比イ形容词：イ形 → 暑かったです；ナ形 → 元気でした。不要混淆。

G3.ナ形容词 + な + 名词连体「な」

ナ形容词修饰名词时必须加「な」，这是它得名的来源。

①静かな 町安静的城市
②きれいな 花漂亮的花
③親切な 人亲切的人
易错：「静かの 町」错误！ナ形修饰名词用「な」不是「の」。「きれい」尾巴是「い」但属ナ形容词，"きれいい"是错的。

G4.どんな Ｎ／〜は どうですか询问印象

どんな Ｎ = "什么样的 N"。〜は どうですか = "〜怎么样？"

①京都は どんな 町ですか。京都是什么样的城市？
②日本語の 勉強は どうですか。日语学习怎么样？
③京都旅行は どうでしたか。京都之行如何？
「どう」是疑问副词，不能直接修饰名词——修饰名词必须用「どんな」。

練習

1. 选用「な」「の」或不加

  1. 静か( ) 町
  2. 日本( ) 友達
  3. きれい( ) 花
  4. 新しい( ) カメラ
▸ 答案
① な ② の ③ な ④ 不加（イ形直接接名词）

2. 变形 + 翻译

  1. 昨天有空。（暇）→
  2. 那位老师不亲切。（親切）→
  3. 京都的红叶非常有名。
  4. 小野是个认真的人。
▸ 答案
① 昨日は 暇でした。
② あの 先生は 親切じゃ ありません。
③ 京都の 紅葉は とても 有名です。
④ 小野さんは 真面目な 人です。
