基本課文 CORE · 日常动作

甲李さんは 毎日 コーヒーを 飲みます。李每天喝咖啡。
甲わたしは 昨日 映画を 見ました。我昨天看了电影。
甲わたしは 毎朝 パンと 卵を 食べます。我每早吃面包和鸡蛋。
甲コンビニで ケーキを 買ってください。请在便利店买蛋糕。
甲朝 何を 食べましたか。早上吃了什么？
乙パンを 食べました。吃了面包。
甲昨日 どこで 晩ご飯を 食べましたか。昨晚在哪里吃晚饭？
乙レストランで 食べました。在餐厅吃的。

応用課文 EXTENDED · 下班后

小野李さん、もう 昼ご飯を 食べましたか。李，午饭吃了吗？
李いいえ、まだです。小野さんは？没，还没。小野呢？
小野わたしも まだです。一緒に 食堂で 食べませんか。我也没。一起去食堂吃吧？
李いいですね。好的。
森李さん、今晩 何を しますか。李，今晚做什么？
李家で 音楽を 聞きます。森さんは？在家听音乐。森呢？
森わたしは 友達と お酒を 飲みます。我和朋友喝酒。
李どこで 飲みますか。在哪里喝？
森新宿の 居酒屋で 飲みます。在新宿的居酒屋。
李いいですね。楽しんで ください。不错呢，玩得开心。

文法

G1.Ｎ(対象) を Ｖます他动词を

を（读 /o/）标示动作的直接对象，相当于汉语宾语。

①コーヒーを 飲みます。喝咖啡。
②本を 読みます。看书。
③日本語を 勉強します。学日语。
「を」作助词时读 /o/，不读 /wo/。自动词不带「を」：行きます／来ます／起きます／寝ます 都不接「を」。

G2.Ｎ(场所) で Ｖます动作场所で

で表示动作发生的场所，区别于表"存在场所"的「に」。

①レストランで 食べます。在餐厅吃。
②図書館で 勉強します。在图书馆学习。
③家で テレビを 見ます。在家看电视。
「で」vs「に」：动作发生 → で（家で 食べます）；存在/到达 → に（家に います）。

G3.Ｎと Ｖます动作伙伴と

在他动词句中，と表示共同动作的伙伴。

①友達と 晩ご飯を 食べます。和朋友吃晚饭。
②家族と 写真を 撮ります。和家人拍照。
③だれと 映画を 見ましたか。和谁看了电影？
一人吃饭说「一人で」：「一人で 食べます」。

G4.何を しますか／いっしょに〜ませんか邀约

「何を しますか」问"做什么"。〜ませんか 是礼貌邀约，"要不要一起〜？"

①今晩 何を しますか。今晚做什么？
②一緒に 昼ご飯を 食べませんか。一起吃午饭吧？
③週末 映画を 見ませんか。周末看电影吧？
应答："いいですね。"（好啊。）／"すみません、ちょっと…"（不好意思，有点…）—— 后者是日式婉拒。

練習

1. 助词填空（を／で／と）

  1. レストラン( ) 晩ご飯( ) 食べました。
  2. 友達( ) 映画( ) 見ます。
  3. 図書館( ) 本( ) 読みます。
  4. 何( ) 飲みますか。
▸ 答案
① で / を ② と / を ③ で / を ④ を

2. 翻译

  1. 我昨天在咖啡馆喝了咖啡。
  2. 一起看电影吧？
  3. 森每天读报纸。
  4. 在哪里买的雑誌？
▸ 答案
① わたしは 昨日 喫茶店で コーヒーを 飲みました。
② いっしょに 映画を 見ませんか。
③ 森さんは 毎日 新聞を 読みます。
④ どこで 雑誌を 買いましたか。
