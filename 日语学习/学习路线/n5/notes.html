第二部分 · 语法

N5 全部 语法点。约 92 条，按 15 大类目分组

每一条包含 句型 · 中文含义 · 一句例句。学的时候先理解句型怎么搭，再背例句 —— 例句是检验你"真的懂了"的最好方法。

A基础判断句Basic copula
01～は～ですA 是 B
私は学生です。我是学生。
02～は～ではありませんA 不是 B
私は先生ではありません。我不是老师。
03～は～ですかA 是 B 吗？
あなたは中国人ですか。你是中国人吗？
04～も～ですA 也是 B
彼も学生です。他也是学生。
05～の～A 的 B
これは私の本です。这是我的书。
06A は B、C は D并列两个判断
これはペン、それは本です。这是笔，那是书。
B助词Particles
07は主题助词
私は田中です。我（这边）是田中。
08が主语助词 / 强调主语
雨が降ります。下雨。
09を宾语助词
本を読みます。读书。
10に时间 / 方向 / 对象
七時に起きます。七点起床。
11で场所 / 手段
学校で勉強します。在学校学习。
12へ方向（读音 e）
日本へ行きます。去日本。
13と和（伴随、并列）
友達と話します。和朋友说话。
14や和（列举不全）
本や雑誌があります。有书、杂志等。
15も也 / 都
私も行きます。我也去。
16の的 / 所属
これは私の鞄です。这是我的包。
17か疑问语气
これは何ですか。这是什么？
18ね确认 / 共感
暑いですね。真热啊。
19よ强调 / 告知
これは安いですよ。这个很便宜哦。
20から从 / 起
九時から始まります。九点开始。
21まで到 / 止
五時まで働きます。工作到五点。
C指示词 こそあどDemonstratives
22これ / それ / あれ / どれ这 / 那 / 那（远） / 哪
これは何ですか。这是什么？
23この / その / あの / どの + 名词修饰名词的"这/那/哪"
この本は私のです。这本书是我的。
24ここ / そこ / あそこ / どこ这里 / 那里 / 哪里
トイレはどこですか。厕所在哪里？
25こちら / そちら / あちら / どちら方向（敬体）
どちらへ行きますか。您去哪边？
D存在 · 拥有Existence
26～に～があります某处有某物
机の上に本があります。桌上有书。
27～に～がいます某处有某人/动物
教室に学生がいます。教室里有学生。
28～は～にあります／います某物在某处
銀行はあそこにあります。银行在那里。
29～には～があります某处的话有什么
部屋には机があります。房间里有桌子。
30～がある／いる拥有 / 存在
妹がいます。我有妹妹。
E数量 · 时间Numbers & Time
31数字 + 量词一冊／二人／三枚
本を三冊買いました。买了三本书。
32～時～分几点几分
今、三時十分です。现在三点十分。
33～月～日几月几日
誕生日は四月八日です。生日是四月八日。
34～曜日星期几
今日は月曜日です。今天是周一。
35～から～まで从…到…
月曜日から金曜日まで働きます。周一到周五工作。
36ぐらい大约（量）
三十分ぐらいかかります。大约要 30 分钟。
37ごろ大约（时间点）
七時ごろ来てください。七点左右来。
38～しか…ない只有…（接否定）
千円しかありません。只有一千日元。
F形容词Adjectives
39イ形容词活用い／くない／かった／くなかった
寒い／寒くない／寒かった／寒くなかった冷／不冷／曾经冷／曾经不冷
40ナ形容词活用だ／ではない／だった／ではなかった
静か／静かではない／静かだった安静／不安静／曾经安静
41形容词 + 名词修饰名词
大きい家、きれいな花大房子、漂亮的花
42～くて／～で形容词连用（接续）
安くておいしいです。便宜又好吃。
43～くなる／～になる变得…
寒くなりました。变冷了。
G动词基本变形Verb conjugation
44ます形礼貌现在 / 未来
毎日勉強します。每天学习。
45～ません礼貌否定
朝ご飯を食べません。不吃早饭。
46～ました礼貌过去
昨日映画を見ました。昨天看了电影。
47～ませんでした礼貌过去否定
行きませんでした。没去。
48辞書形字典原形
食べる、行く、する吃、去、做
49ない形否定形（简体）
食べない、行かない、しない不吃、不去、不做
50た形过去形（简体）
食べた、行った、した吃了、去了、做了
51て形连接 / 各种语法基础
食べて、行って、して吃了之后、去了之后
Hて形相关句型Te-form patterns
52～てください请做…
静かにしてください。请安静。
53～ています正在 / 状态持续
今、本を読んでいます。现在在读书。
54～てもいいです可以做…
ここで写真を撮ってもいいですか。这里可以拍照吗？
55～てはいけません不可以…
ここで吸ってはいけません。这里不能吸烟。
56～ないでください请不要做…
心配しないでください。请别担心。
57～なければなりません必须做…
宿題をしなければなりません。必须做作业。
58～なくてもいいです不做…也可以
行かなくてもいいです。不去也可以。
I愿望 · 邀请Desire & Invitation
59～たいです想做…
日本へ行きたいです。想去日本。
60～がほしいです想要…（东西）
新しい車がほしいです。想要新车。
61～ましょう一起…吧
一緒に食べましょう。一起吃吧。
62～ましょうか我（们）…吧？
窓を開けましょうか。我开窗好吗？
63～ませんか不…吗？（邀请）
一緒に行きませんか。一起去吗？
J能力 · 喜好Ability & Preference
64～ことができます能 / 会做…
日本語を話すことができます。会说日语。
65名词 + ができます会某项技能
ピアノができます。会弹钢琴。
66～が好き／嫌い喜欢 / 讨厌
猫が好きです。喜欢猫。
67～が上手／下手擅长 / 不擅长
歌が上手です。唱歌很棒。
K表达 · 推测Expression & Conjecture
68～と思います我认为…
明日は雨だと思います。我觉得明天会下雨。
69～と言いました某人说…
田中さんは「行く」と言いました。田中说"去"。
70～でしょう大概…吧
明日は晴れるでしょう。明天大概会晴。
71～かもしれません也许…
雨が降るかもしれません。也许会下雨。
L时间表达Time expressions
72～前に在…之前
寝る前に歯を磨きます。睡前刷牙。
73～後で在…之后
食事の後で散歩します。饭后散步。
74～時…的时候
子供の時、よく泣きました。小时候经常哭。
75～ながら一边…一边
音楽を聞きながら勉強します。边听音乐边学习。
76～てから…之后再
手を洗ってから食べます。洗手后再吃。
M接续Conjunctions
77～から（理由）因为…
寒いから、コートを着ます。因为冷，所以穿外套。
78～ので因为…（柔和）
雨が降っているので、行きません。因为下雨，不去了。
79～が（但是）但是…
高いですが、買います。虽然贵但要买。
80～けど但是…（口语）
おいしいけど、高い。好吃但贵。
81そして然后 / 还有
安いです。そして、おいしいです。便宜。而且，好吃。
82それから然后（动作顺序）
朝ご飯を食べました。それから、出かけました。吃了早饭，然后出门了。
83でも但是（口语）
疲れた。でも、楽しかった。累了，但很开心。
84しかし但是（书面）
努力した。しかし、失敗した。努力了，但失败了。
N比较Comparison
85A と B とどちらが…A 和 B 哪个更…
コーヒーと紅茶とどちらが好きですか。咖啡和红茶你更喜欢哪个？
86A より B のほうが…B 比 A 更…
日本より中国のほうが大きいです。中国比日本大。
87一番最…
一番好きな食べ物は寿司です。最喜欢的食物是寿司。
O经验 · 建议 · 其他Misc
88～たことがあります曾经做过…
日本へ行ったことがあります。去过日本。
89～たほうがいいです最好做…
早く寝たほうがいいです。最好早睡。
90～たり～たりする又…又…（举例）
週末は読書したり、映画を見たりします。周末又看书又看电影。
91～でした名词过去时
昨日は雨でした。昨天下雨了。
92～になる成为 / 变为
医者になりたいです。想成为医生。
