第一章 · 阶段定位

N4 是真正的语法。从这里开始能写复杂句子

N4 阶段你能：写日记、读简单漫画、听慢速日剧能跟上一半。词汇约 1300（含 N5 的 800），汉字 300 左右。能用动词的各种变形造复杂句。不能看新闻、不能正常对话、不能读小说 —— 那些要到 N3 之后。

N4 vs N5 的关键差别

动词、条件、敬语，三件事而已

动词变形彻底掌握。N5 学了 ます／て／ない／た 形，N4 要学被动（受身）、使役（使役）、可能（可能）、命令（命令）、意志（意志）。同一动词有 8 种形式。

条件句进入体系。"如果...就..." 在日语里有 4 种说法（と、ば、たら、なら），各有微妙差别。N4 阶段把它们分清楚是基本功。

敬语开始入门。不是 N4 重点，但 です/ます 之外的高级敬体（お＋ます形、ご＋名词、いらっしゃる、おっしゃる）开始出现。

N4 最大的山不再是 N5 的"五十音 + 动词分类"，而是"变形迷宫"。同一个动词，被动/使役/可能/命令 4 种形式各有规则，要专门整理一张大表反复练。
第二章 · 学习计划

六到十个月，分八步走。动词变形占两个月

假设每天 1–1.5 小时。N4 比 N5 难度上升一个台阶，所以时间也长一些。关键阶段：动词的被动/使役/可能 —— 这是 N4 最容易掉队的地方。

第三章 · 重点讲解

N4 的核心难点。学透这 12 个点，剩下都是细节

完整语法表见笔记页。这里只挑出 N4 学习者最常卡的 12 个核心点。

① 自他动词 · 一对一对地记

日语的自他动词比英语强迫症得多

同一概念常有两个动词：自动词（不带宾语）和 他动词（带宾语）。例：

ドアが開く / ドアを開ける门开了（自） / 我开门（他）
電気が消える / 電気を消す灯灭了（自） / 我关灯（他）

规律：他动词常用 -eru/-asu 结尾，自动词常用 -aru/-eru/-iru 结尾。但例外极多，建议成对死记。常见对子：始まる/始める、終わる/終える、止まる/止める、変わる/変える。

N4 阅读理解最喜欢考自他混淆。学到一个新动词，立刻查它的"对子" 一起背。

② 受身形（被动） · られる 的真正含义

日语被动比英语用得多得多

变形：I 类 う段→あ段+れる（書く→書かれる），II 类 +られる（食べる→食べられる），III 类 する→される、来る→こられる。

先生に褒められました。被老师表扬了。
雨に降られて、濡れた。被雨淋了（讨厌的被动）。

注意 "迷惑被动"：日本人常用被动表达"被困扰"（即使主语没有被动作影响）。"妻に死なれて..." 直译"被妻子死了"，实指"妻子去世，我受影响"。中文很少这样表达。

③ 使役形 · させる 让某人做

命令、允许、放任三种语气都用同一形

变形：I 类 う段→あ段+せる（書く→書かせる），II 类 +させる（食べる→食べさせる），III 类 する→させる、来る→こさせる。

親が子供に薬を飲ませる。家长让孩子喝药。
先生は学生を立たせた。老师让学生站起来。

注意区别："AがBに～させる"（A让B做） vs "AがBを～させる"（A让B做，B是被动受动作者）。用に还是を取决于动词及物性。

④ 使役被动 · させられる "被迫做"

日语阴暗面的高频表达

变形：使役形 + られる。例：食べる→食べさせられる（被迫吃）。I 类有"省略形"：書く→書かされる（不是 書かせられる）。

先生に長い宿題をさせられた。被老师强迫做了长作业。
日本人特别爱用这个形表达"我虽然做了但其实是被强迫的"。在职场对话里高频出现。

⑤ 条件 と / ば / たら / なら 的差别

日语条件四兄弟，各有用法

～と：客观必然结果（押すと開く）。
～ば：假设性强，常用于谚语和劝告（早く来れば良かった）。
～たら：最通用，可表过去/未来/假设（家に着いたら電話して）。
～なら：基于对方的话/话题假设（東京へ行くなら、新幹線で）。

勉強すると、成績が上がる。学习的话，成绩就会上去（普遍规律）。
時間があれば、行きます。有时间的话，就去（假设）。
日本に着いたら、メールしてください。到日本后，请发邮件（具体未来事件）。
日本に行くなら、京都がおすすめです。如果要去日本，推荐京都（基于对方表达的意图）。
迷茫时优先用 たら，最通用最不会错。掌握后再细分使用场景。

⑥ そう / らしい / みたい / ようだ · 四种"像"

推量体系的四个声调

～そう：眼睛看到的瞬间判断（おいしそう "看起来好吃"）。
～らしい：根据传闻或外部信息（雨が降るらしい "听说要下雨"）。
～みたい：口语，主观比喻（雨みたいに泣いた "像下雨一样哭"）。
～ようだ：書面，对感知/证据的推测（雨のようだ "看样子下雨"）。

そう = 看见即觉得，らしい = 听说，みたい = 像，ようだ = 推测。这四个 N4 阶段一定要分清。

⑦ あげる / くれる / もらう · 授受关系

日语视角问题：以"我"为中心

あげる：我或第三者 → 他人（"给"）。
くれる：他人 → 我或我的圈子（"给我"）。
もらう：我从他人那里得到（"接收"）。

私は彼に本をあげた。我给了他书。
彼は私に本をくれた。他给了我书。
私は彼に本をもらった。我从他那里得到了书。

更复杂：补助动词 ～てあげる / ～てくれる / ～てもらう 表示"做某事给某人"。日本人非常注重这个"恩惠方向"。

⑧ 敬语初步 · 三套体系

不是 N4 重点，但要看得懂

尊敬语（说话人尊敬对方）：お＋ます形＋になる（お書きになる）、いらっしゃる（行く/来る/いる）、おっしゃる（言う）。

谦让语（说话人谦虚自己）：お＋ます形＋する（お書きします）、参る（行く/来る）、申す（言う）。

丁寧语：です/ます（N5 复习）。

N4 阶段记住核心 10 个常用动词的三种形（行く、来る、いる、する、言う、見る、食べる、知る、思う、ある）就够了。完全掌握敬语是 N3-N2 的事。

⑨ つもり / 予定 / つもりだった · 计划与意图

表达"打算" 的三个层次

～つもり：个人主观打算（明日は早く起きるつもりです）。

～予定：已确定的计划安排（来週、出張する予定です）。

～つもりだった：本来打算（行くつもりだったが、雨で中止）。

⑩ ように / ために · "为了"的两种说法

主观 vs 客观目的

～ように：愿望/能力，主语和后句主语可不同（聞こえるように大きい声で話す）。

～ために：明确目的，主语必须一致（健康のために運動する）。

日本語が話せるようになる。变得能说日语。
家を買うために貯金する。为了买房而存钱。

⑪ ところ 三兄弟 · 时间点表达

即将、正在、刚才

動詞辞書形 + ところ：正要做（今出かけるところです）。
動詞ている形 + ところ：正在做（今食べているところです）。
動詞た形 + ところ：刚做完（今帰ったところです）。

这三个的时间感很微妙：辞書形 = 还没开始、ている = 进行中、た = 刚刚完成。中文常翻译成"正"，但语感不同。

⑫ ばかり 系列 · 仅仅、刚刚、净是

N4 的高频词

名词 + ばかり：只有/净是（マンガばかり読む "净看漫画"）。

動詞た形 + ばかり：刚刚（食べたばかりです "刚吃过"）。

動詞ている + ばかり：一直在/光（泣いてばかりいる "光哭"）。

第四章 · 怎么背词汇

N4 是词汇翻倍期。N5 的 800 → N4 的 1300

原则一 · 切换到 Core 2k/6k

N5 的 Kaishi 1.5k 已经背得差不多了。N4 阶段切换到 Anki Core 2k，这个卡组覆盖了 N4 全部高频词 + N3 入门词。

每天 15–20 个新词，配合复习。比 N5 略多一点点，但仍然要保证记得牢而不是"过得快"。

原则二 · 开始挖词（Mining）

N4 后期开始尝试 从阅读中挖词。流程：用 Yomitan 浏览器扩展划词查意，看到不会的词一键加入 Anki。

挖词卡和固定卡组的最大不同：挖来的词必定是你阅读上下文里遇到的，所以记得快、忘得慢。

原则三 · 动词区别要单独建表

N4 阶段动词的"对子"（自他、被动/使役）非常多。建议自己用 Anki 自建动词矩阵卡：

正面：基础动词（如 食べる）
反面：可能形 / 被动形 / 使役形 / 使役被动形 / 命令形 / 意志形

每天复习 5–10 个动词的全部变形，半年内动词变形再不会卡。
