# JLPT 官方样题

来源：日本语能力测试 JLPT 官方网站样题页  
https://www.jlpt.jp/samples/sampleindex.html

当前已下载：`2018` 版官方问题集样题，覆盖 N1-N5。

## 文件说明

每个级别包含以下 PDF：

- `N*V.pdf`：文字・語彙
- `N*G.pdf`：文法
- `N*R.pdf`：読解
- `N*L.pdf`：聴解
- `N*answer.pdf`：答案
- `N*script.pdf`：听力原文
- `N*sheet.pdf`：答题卡

听力音频放在 `2018/mp3/`：

- N1-N3：`Q1` 到 `Q5`
- N4-N5：`Q1` 到 `Q4`
