🔥 我的总规划：15 周冲刺版

2026/06/08 → 2026/09/20 · 104 天 · 每日 3-4 小时 · 目标客观题过线

总学时 ~360h 三大科占 60% 真题轮占 25%
残酷的现实：距离今年 9/20 客观题考试只剩 104 天。零基础正常需要 8-10 个月，现在压缩到 3.5 个月。 必须做减法：放弃"全面覆盖"，只攻三大科 + 真题套路。其他学科靠"考前 30 天突击 + 蒙题技巧"。

⚡ 本规划的 3 个核心取舍

  1. 放弃主观题——今年只考客观题。主观题明年再考（客观成绩 2 年有效）。
  2. 放弃精通——三大科吃 70%、二线 50%、三线 30% 就够过线。
  3. 放弃章节题海——每科只刷"高频题 + 真题"，不做章节题大全。时间不够。

一、时间账（先算明白再开始）

项目数值备注
今天2026/06/08（周一）—
客观题考试预计 2026/09/19-20（周末）以司法部公告为准
剩余天数约 104 天 ≈ 15 周含周末
每日学习3.5 小时（工作日）/ 6 小时（周末）—
周学时3.5 × 5 + 6 × 2 = 29.5 小时—
总学时约 360 小时15 周 × 29.5h，扣 30h 应急余量
360 小时够过客观题吗？临界值。有法学基础者 250h 足够，零基础正常需要 500h+。 你处于"极限挤压区间"——必须严格按本规划走，不能再削减时长。 如果第 4 周仍未掌握刑法三阶层，建议把目标调整为"试水年"。

📕 阶段 A · 三大科攻坚（第 1-9 周）

W1（6/8 - 6/14）刑法总论 1

  • Day 1（今天）：跟 1 个视频"什么是三阶层"+ 本站刑法页导论
  • Day 2-3：构成要件该当性（行为 / 结果 / 因果 / 主体）
  • Day 4：违法性（正当防卫 / 紧急避险 / 被害人承诺）
  • Day 5：有责性（责任年龄 / 责任能力 / 违法性认识）
  • Day 6-7：错误论（事实错误 / 法律错误）+ 本周整理
  • 题量：80 道章节题

W2（6/15 - 6/21）刑法总论 2

  • 故意 / 过失
  • 共同犯罪（主犯 / 从犯 / 教唆 / 帮助 / 共犯过限）
  • 未完成形态（预备 / 未遂 / 中止）
  • 罪数（一罪 / 数罪 / 想象竞合 / 法条竞合 / 牵连犯）
  • 题量：100 道

W3（6/22 - 6/28）刑法分则 1

  • 侵犯人身权利罪（杀人 / 伤害 / 强奸 / 绑架 / 非法拘禁）
  • 侵犯财产罪（盗窃 / 抢劫 / 诈骗 / 侵占 / 敲诈勒索 / 抢夺）
  • 重点：能区分易混罪——盗 vs 抢 vs 诈 vs 侵占
  • 题量：120 道

W4（6/29 - 7/5）刑法分则 2 + 收尾

  • 经济犯罪（合同诈骗 / 虚开发票 / 洗钱）
  • 贪污贿赂罪（贪污 / 受贿 / 行贿）
  • 渎职罪（玩忽职守 / 滥用职权）
  • 本周末：做 1 套近 3 年刑法真题（自测得分 ≥ 25/45 即合格）
  • 题量：120 道 + 1 套真题
跟课推荐：柏浪涛（厚大）2026 精讲。先听后做题，不要 1.5 倍速。

W5（7/6 - 7/12）民法 1 · 总则 + 物权

  • 民事主体（自然人 / 法人 / 非法人组织）
  • 民事法律行为（成立 / 生效 / 效力瑕疵）
  • 代理（一般 / 表见 / 无权）+ 诉讼时效
  • 物权·所有权 + 用益物权 + 善意取得
  • 题量：120 道

W6（7/13 - 7/19）民法 2 · 合同（最重）

  • 合同总则（成立生效 / 履行 / 违约责任 / 解除）
  • 违约金调整规则 + 定金规则
  • 合同分则（买卖 / 租赁 / 借款 / 保证 / 委托）
  • 本周是民法分值最重的一周——别懒
  • 题量：150 道

W7（7/20 - 7/26）民法 3 · 侵权 + 婚家继承

  • 一般侵权 + 8 种特殊侵权
  • 担保物权（抵押 / 质押 / 留置）
  • 婚姻家庭（夫妻财产 / 离婚 / 收养）
  • 继承（法定继承 + 遗嘱继承 + 代位继承）
  • 题量：130 道

W8（7/27 - 8/2）民法收尾 + 真题

  • 把前 3 周薄弱章节重听 1 遍
  • 本站速记口诀民法部分背完
  • 周末：1 套近 3 年民法真题（自测 ≥ 30/55 即合格）
  • 题量：80 道 + 1 套真题
跟课推荐：钟秀勇（瑞达）民法。学完一章就做对应章节题，不要堆到后面。

W9（8/3 - 8/9）行政法 1 周打透

  • Day 1-2：行政主体 + 行政行为（许可 / 处罚 / 强制）
  • Day 3：行政复议（申请期 60 日 / 复议机关 / 决定类型）
  • Day 4-5：行政诉讼（受案范围 / 管辖 / 一审/二审/再审）
  • Day 6：国家赔偿（行政赔偿 + 刑事赔偿 + 计算公式）
  • Day 7：画"违法行政 → 复议 → 诉讼 → 赔偿"完整程序图
  • 题量：100 道 + 1 套近年真题

📙 阶段 B · 二三线速通（第 10-12 周）

本阶段心态：不要追求"听懂每一句"。每科只给 1 周——视频 1.5 倍速 + 做高频题 + 背口诀。 会做就行，不求精通。

W10（8/10 - 8/16）刑诉法

  • 管辖 + 回避 + 辩护 + 强制措施（拘留 / 逮捕 / 取保 / 监居）
  • 证据（非法证据排除 / 证人证言）
  • 程序（侦查 → 审查起诉 → 一审 → 二审 → 死刑复核）
  • 记关键期限数字：拘留期 14 日、提请审查 7 日、审判期 3 个月…
  • 题量：100 道

W11（8/17 - 8/23）民诉法

  • 管辖（级别 + 地域 + 协议 + 专属）
  • 证据 + 证据期限
  • 简易 / 普通 / 小额诉讼程序
  • 执行 + 仲裁
  • 题量：100 道

W12（8/24 - 8/30）商经 + 理论 + 三国

子任务时长重点
商经知（公司+票据+知产）3 天公司决议效力、票据追索、著作权/商标
理论法2 天法治理论 + 职业道德 + 宪法监督（纯背诵）
三国法1 天外交豁免 + 信用证 + 冲突规范（看一遍精简班）
整阶段串联 + 错题1 天—
速通秘诀：这周不看完整精讲，只看老师的"30 天速通班"或"考前聚焦"。 直接学"考什么"，不学"为什么"。

📔 阶段 C · 真题 + 冲刺（第 13-15 周）

W13（8/31 - 9/6）近 5 年真题第 1 遍

  • 按学科做（不按年度）：刑法所有真题 → 民法所有真题 → 以此类推
  • 每道错题必须写出：① 考点 ② 错的原因 ③ 关联知识点
  • 每天 4 小时刷题 + 2 小时整理错题本
  • 目标：错题本积累 150+ 道

W14（9/7 - 9/13）近 5 年真题第 2 遍 + 模考

  • 这次按年度做：1 天 1 套（卷一 + 卷二）
  • 限时模拟：上午 8:30-11:30 卷一，下午 14:00-17:00 卷二
  • 评分目标：单套 ≥ 180 分
  • 错题本第 2 轮过一遍

W15（9/14 - 9/19）临考收尾

日期任务禁忌
9/14（周一）错题本第 3 轮 + 必背清单不接触新题
9/15（周二）速记口诀全背 1 遍不熬夜
9/16（周三）1 套全真模拟（最后一次）不分析新难题
9/17（周四）过本站所有学科页"重点速览"不打击信心
9/18（周五）准备文具 / 准考证 / 身份证 + 早睡不学习新内容
9/19（周六）客观题卷一 + 卷二考试—
临考 3 大忌：不熬夜！不看新题打击信心！不喝太多咖啡致心慌！

🏁 五、6 个关键里程碑

每个节点对照自测。未达标的强烈建议调整目标。

刑法收尾

  • 能默写三阶层 + 共犯类型
  • 能背 12 个常考罪构成
  • 近年刑法真题 ≥ 25/45

里程碑 2（8/2 · W8 末）

民法收尾

  • 能数出 19 种典型合同
  • 能背善意取得 / 表见代理要件
  • 近年民法真题 ≥ 30/55

里程碑 3（8/9 · W9 末）

行政法收尾

  • 画出复议+诉讼+赔偿完整流程图
  • 背完所有期限数字（60/15/6 等）
  • 近年行政真题 ≥ 16/30

里程碑 4（8/30 · W12 末）

二三线全部学完

  • 5 科各听过 1 遍精讲
  • 各科背完老师的"考前聚焦"

  • 近 5 年真题做 2 遍
  • 套卷模拟稳定 ≥ 170 分
  • 错题本 ≥ 200 道且能讲清

心态收尾

  • 准考证 / 身份证 / 文具准备好
  • 考场踩点（如本地有 / 异地考）
  • 22:30 前睡，不熬夜

🚨 六、进度落后的应急预案

触发条件应对策略
W4 末刑法没收完 压缩民法 1 周（合并 W7/W8），把刑法挪到 W5。代价：民法精度下降。
W8 末民法没收完 砍 W11 民诉（只刷真题不听讲），腾出 1 周给民法兜底。
W9 末行政法没学透 放弃行政法细节，只背"程序图 + 受案范围 + 复议期限"3 个核心点。
W12 末二三线没扫完 跳过三国法精讲，直接背口诀 + 在考场上蒙。三国法蒙题正确率约 35%。
W13 真题做了一遍发现得分远低于 180 立即识别"丢分大户"——通常是民法或刑诉。W14 全力补该科，放弃其他。
W14 模拟仍 < 150 切换"试水年"心态。考完后立即开始备 2027 年。今年成绩仅作压力测试。
"试水年"不是失败。零基础 104 天能拿 150-170 分已经很强。下半年 9/20 考完后到次年 6 月还有 9 个月—— 那时你已经有基础，再冲一年就稳了。客观题成绩 2 年有效，今年过线就明年只考主观；今年没过就明年从客观再来。
